# DEF — Post‑Punk Robotic Store

Este documento define a **direção visual e prompts de imagem** para os fundos de páginas de venda da loja **DEF**, baseada em uma estética **pós‑punk robótica / industrial / cyber‑decay**.

---

## 🎛️ Direção Visual Base (Global)

Aplicável a todas as categorias:

* **Paleta:** preto profundo, cinza chumbo, aço escovado, neon vermelho e verde ácido
* **Texturas:** concreto rachado, metal oxidado, fios expostos, glitch digital
* **Iluminação:** luz lateral dura, sombras longas, fumaça leve, reflexos neon
* **Clima:** frio, urbano, funcional, anti‑luxo, distópico
* **Estilo:** cinematic wide shot, brutalism, post‑punk cyber aesthetic

Sugestão de sufixo global para geração:

```
--no people --no text --cinematic lighting --high contrast
```

## 🧠 Nota Conceitual

A **DEF** não é uma loja tradicional.

DEF não é loja.
É catálogo de sobrevivência pós-sistema.

Ela se posiciona como um **catálogo de sobrevivência pós‑sistema**, onde cada produto parece ter sido projetado para um mundo urbano hostil, tecnológico e funcional.

Este arquivo serve como **fonte única de verdade visual** para geração de imagens, automação de conteúdo e padronização estética da marca.


DEF não é loja.
É catálogo de sobrevivência pós-sistema.

Ela:

cria distanciamento do e-commerce comum

posiciona a DEF como curadoria, não vitrine

conversa com gente que não quer luxo, quer ferramenta

sustenta toda a estética pós-punk sem parecer fantasia



“Não vendemos coisas. Distribuímos equipamento.”

“Para quem vive depois do sistema.”

“Designado para ambientes hostis.”

“Funcional. Frio. Necessário.”

“Nada aqui é decorativo.”

A DEF já tem algo raro: coerência conceitual.
Agora é só repetir isso em tudo — imagem, texto, produto, silêncio.
